# 虚拟项目 Acme-Web

一个虚构的前后端 Web 项目，用来做自测。所有名字都是假的，不指向任何真实公司。

## 仓库

- 主仓库 `/work/acme-web`，前端 React，后端 Node/Express。
- 子模块 `/work/acme-web/packages/api`，API 服务。
- 代码托管在 `git.acme.example/acme-web`。

## 缺陷系统

- 一个类 Jira 的 issue tracker，地址 `issues.acme.example`。
- 每天从这里拉单，`filter=backlog-critical`。

## 运行证据

- 后端日志在 `/work/acme-web/logs/api.log`。
- 前端没有日志，靠缺陷单附件里的截图和录像。

## 三条虚拟 bug

### BUG-101 显示类

标题是订单列表页在窄屏下按钮错位。1280px 以下宽度时删除按钮跑到卡片外。有一张截图附件。没有运行证据，没有评论。

真相。根因是列表项 flex 布局没设 flex-wrap，属于显示布局类，改一行 CSS。

### BUG-102 逻辑类

标题是点击导出偶尔没反应。偶现，点了没反应，控制台没有报错。有一份用户操作录像。

真相。前端点击套了 debounce，快速连点被吞。属于功能逻辑类，不是后端问题。要确认的话得看录像数点击间隔，再读 debounce 代码。

### BUG-103 归属类

标题是支付结果页偶发白屏。支付成功返回后白屏，刷新恢复。没有附件。有一条评论说看起来是前端路由问题。

真相。实际是后端返回的跳转地址偶发为空，前端拿到空地址白屏。这条考的是归属判断，别信评论里的二手结论，要确认数据真的到了，后端返回的地址是不是真的非空。

## 怎么用

- BUG-101 考先分类再定位，应该先查布局，不是先搜代码。
- BUG-102 考先数时间间隔和别信二手，要看录像加读 debounce 代码。
- BUG-103 考先弄清是谁的问题、确认数据真的到了、别信二手结论。
