## 四，发现

1. git_recent 在没有远程的仓库上 pull 会报错，但报错后继续走 git log，不崩。这个行为可以接受，有远程的正常项目不受影响。
2. git_push_verify 的成功标记覆盖两类平台，普通托管的 new branch，审查流程的 SUCCESS 和 refs/for。但推送引用不一样，普通托管用 `HEAD:main`，审查流程用 `refs/for/main`，用的时候按平台传 --ref。这是已知边界，写进了脚本注释。
