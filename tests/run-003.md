1. 自动化启动前，关掉已开的同款浏览器，或换独立用户目录。机制无关 ✓
2. 慢页面留足超时，别把慢当挂。机制无关 ✓
3. 下载串行，别并发。机制无关 ✓，和 loop 里已有的"一次只分析一条"呼应
4. 下载失败不等于没有。机制无关 ✓，这条同时补进了 depth-gate 的信息不足判定
5. 大附件可能在外部对象存储，接口里找不到不等于没有。机制无关 ✓
6. 凭证不写脚本，复用已登录会话。机制无关 ✓，和 bootstrap 的凭证红线一致
7. 机制坏了先跑最小复现。机制无关 ✓，和 bootstrap 的 --demo 验一遍呼应

全文没有出现任何具体浏览器名、自动化库名、安装路径、平台路径。方法一律指向适配层，照着 example_api.py 的样板接。
