# 项目类型适配怎么写

核心流程不挑项目类型，但每种项目类型的判断方法不一样。Java 项目、C++ 项目、Web 项目、嵌入式项目，分类法不同，专属检查项不同，词汇不同。项目类型适配就是把这些不同装进一个文件夹，让核心流程在这种项目类型里能落地。

## 一个项目类型适配包要有什么

```
references/project-types/你的项目类型/
├── README.md          这种项目类型的说明，什么时候用
├── classification.md  这种项目类型的分类法，先分类再定位怎么分
├── checks.md          这种项目类型的专属检查项，按分类列
└── vocabulary.md      这种项目类型的常用词和概念，信号、映射、字段这些
```

## 四份文件各回答一个问题

1. README.md。什么项目用得上这份适配，什么项目用不上。
2. classification.md。这种项目类型最常见的症状分几类。
3. checks.md。每一类症状，先查什么，再查什么。
4. vocabulary.md。这种项目类型里配置映射、数据没到、版本太旧这类事，通常长什么样。

## 写完怎么验

拿三条这种项目类型的真实 bug 走一遍。分类能对上，检查项能指引方向，词汇表能被搜到，就算合格。写不出分类法的类型，说明还没摸清这种项目，先别写。
